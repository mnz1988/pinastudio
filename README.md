# وبسایت پورتفولیو — راهنما

استک: **Next.js (App Router) + TypeScript + Tailwind CSS v4 + Prisma + NextAuth v5**

ویژگی‌ها:
- صفحه اول با تصویر سیاه‌وسفید (نسخه عمودی برای موبایل / افقی برای دسکتاپ) و متن چرخشی فارسی/انگلیسی
- ترنزیشن پیکسلی بین صفحات (لوگو)
- صفحات: خانه، درباره من، پورتفولیو (با پاپ‌آپ)، صفحه کامل هر پروژه، ارتباط با من
- عضویت کاربران + ثبت سفارش سفارشی (بدون درگاه پرداخت — ادمین سفارش‌ها را در پنل می‌بیند و برای هماهنگی مبلغ/جزئیات با کاربر تماس می‌گیرد)
- پنل ادمین کامل (`/admin`) برای مدیریت پروژه‌ها، متن‌های صفحه اول، متن درباره‌من، پیام‌ها و سفارش‌ها — بدون نیاز به دیتابیس یا کد جدا برای هر تغییر محتوا

---

## ۱) اجرای آزمایشی روی سیستم شخصی (لوکال)

پیش‌نیاز: Node.js نسخه ۱۸ به بالا.

```bash
# نصب پکیج‌ها (به‌صورت خودکار prisma generate هم اجرا می‌شود)
npm install

# ساخت فایل env از روی نمونه (اگر از قبل .env ندارید)
cp .env.example .env

# ساخت دیتابیس SQLite لوکال و جداول
npx prisma migrate dev --name init

# ساخت کاربر ادمین اولیه + محتوای نمونه
npm run seed

# اجرای سرور توسعه
npm run dev
```

سایت روی `http://localhost:3000` بالا می‌آید.
برای ورود به پنل ادمین به `http://localhost:3000/login` بروید — ایمیل و رمز عبور همان مقادیر `ADMIN_EMAIL` و `ADMIN_PASSWORD` در فایل `.env` است (پیش‌فرض: `admin@example.com` / `change-me-please` — حتماً قبل از هر کار عوضش کنید).

## ۳) دیپلوی روی Vercel

### الف) تغییر دیتابیس به Postgres
SQLite برای هاست‌های سرورلس مثل Vercel مناسب نیست (فایل‌سیستم موقتی و غیرقابل‌اتکاست). قبل از دیپلوی:

1. یک دیتابیس Postgres رایگان بسازید (پیشنهاد: [Neon](https://neon.tech) یا Vercel Postgres از تب Storage در داشبورد Vercel).
2. در `prisma/schema.prisma` خط زیر را:
   ```prisma
   provider = "sqlite"
   ```
   به این تغییر دهید:
   ```prisma
   provider = "postgresql"
   ```
3. تغییرات را کامیت و پوش کنید.

### ب) اتصال ریپازیتوری به Vercel
1. وارد [vercel.com](https://vercel.com) شوید → **Add New Project** → ریپازیتوری گیت‌هاب را انتخاب کنید.
2. فریم‌ورک به‌صورت خودکار Next.js تشخیص داده می‌شود.
3. در بخش **Environment Variables** مقادیر زیر را اضافه کنید (از `.env.example` الگو بگیرید):

   | Key | مقدار |
   |---|---|
   | `DATABASE_URL` | کانکشن‌استرینگ Postgres شما |
   | `AUTH_SECRET` | یک رشته تصادفی امن (با `openssl rand -base64 32` بسازید) |
   | `AUTH_TRUST_HOST` | `true` |
   | `NEXTAUTH_URL` | آدرس نهایی سایت شما، مثلاً `https://yourdomain.vercel.app` |
   | `NEXT_PUBLIC_SITE_URL` | همان آدرس بالا |
   | `ADMIN_EMAIL` / `ADMIN_PASSWORD` | برای اجرای seed |

4. روی **Deploy** بزنید.
5. بعد از اولین دیپلوی موفق، یک‌بار از طریق ترمینال (لوکال، با `DATABASE_URL` همان Postgres پروداکشن در `.env`) دستورات زیر را اجرا کنید تا جداول و کاربر ادمین ساخته شوند:
   ```bash
   npx prisma migrate deploy
   npm run seed
   ```

بعد از این مراحل، هر بار که کد را روی شاخه `main` پوش کنید Vercel به‌صورت خودکار دوباره دیپلوی می‌کند.

## ساختار پروژه (خلاصه)

```
app/
  page.tsx                → صفحه اول
  about/, contact/         → صفحات ثابت
  portfolio/                → لیست + صفحه هر پروژه
  order/, register/, login/ → عضویت و ثبت سفارش
  admin/                    → پنل ادمین (محافظت‌شده با middleware.ts)
  api/                      → مسیرهای API (contact, orders, payment, auth)
components/                → کامپوننت‌های رابط کاربری
lib/                        → Prisma client + اتصال درگاه پرداخت
prisma/schema.prisma        → مدل دیتابیس
prisma/seed.ts              → ساخت ادمین اولیه
```

## نکات مهم امنیتی قبل از استفاده واقعی
- حتماً `ADMIN_PASSWORD` را در `.env` قبل از seed تغییر دهید.
- `AUTH_SECRET` باید یک مقدار تصادفی و طولانی و مخفی باشد (هرگز آن را در گیت‌هاب کامیت نکنید).
- فعلاً هیچ درگاه پرداختی متصل نیست؛ سفارش‌های سفارشی فقط ثبت و در پنل ادمین (`/admin/orders`) نمایش داده می‌شوند تا خودتان دستی پیگیری/پرداخت را هماهنگ کنید. اگر بعداً خواستید پرداخت آنلاین اضافه کنید، بگویید تا اضافه‌اش کنم.
